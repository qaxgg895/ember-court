Ember Court is an original duel card game: two lantern-keepers, 24 life each, trading guardians, strikes and charms across a candle-lit table until one lantern goes dark. Play it against Mira, an AI keeper whose choices you can read and counter.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network, just static files under game/.
